# Mini-site De Vlieger

Website van jeugdvereniging De Vlieger.

## Benodigdheden
- Git
- Docker Engine
- Docker Compose

## Installatie
Clone de repository en open de projectmap.

## Website starten
Voer uit: sudo docker compose up -d

Open http://localhost:8080 in je browser.

## Website stoppen
Voer uit: sudo docker compose down
